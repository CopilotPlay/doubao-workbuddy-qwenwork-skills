# 财税中介机构AI合规专家团 - 使用指南

> 本指南帮助客户端 agent 和用户提供高效使用建议。

## 专家团架构

### 主理人：事务所供给侧总监
负责复杂跨域财税诉求分诊，协调专题专家协同处理。

### 专题专家（4位）
1. **中介机构智能合规咨询专家** - 合规咨询转型、风险识别
2. **合同涉税评审与风控专家** - 合同生成、涉税审核、风险防控
3. **法税同审与法务审查专家** - 法税同审落地、法务合规
4. **特色事务所战略定位专家** - 事务所差异化战略、特色化转型

## 快速开始

1. **描述诉求**：用自然语言说明你的需求（如"帮我分析客户的税务合规风险"）
2. **自动分诊**：主理人识别所属领域，匹配对口专家
3. **专家执行**：专家调用财税政策知识库与风险模型
4. **一体化交付**：主理人汇总各专家结论，生成结构化报告
5. **多轮追问**：可针对具体结论继续追问细节

## 典型工作流示例

### 示例1：股权转让风险综合评估
```
用户："我们公司股权转让有什么风险？"
→ 主理人分诊：识别为股权交易场景
→ 派单：中介机构智能合规咨询专家
→ 专家执行：调用 risk_check 工具，识别 10 项股权风险点
→ 返回：风险清单 + 政策依据 + 应对建议
```

### 示例2：合同涉税审核
```
用户："帮我审核这份销售合同"
→ 主理人分诊：识别为合同审核场景
→ 派单：合同涉税评审与风控专家
→ 专家执行：调用合同模板 + 风险模型
→ 返回：合同涉税风险点 + 修订建议
```

### 示例3：法税同审合规体系搭建
```
用户："如何构建法税同审合规体系？"
→ 主理人分诊：识别为体系建设场景
→ 派单：法税同审与法务审查专家 + 特色事务所战略定位专家
→ 专家协同：法税同审专家提供合规框架，战略专家提供转型路径
→ 返回：体系建设方案 + 实施路径
```

## 能力底座

本专家团依托主技能「财税政策知识库」三大专业底座：

1. **全量财税知识库**：覆盖 13 个税种 + 7 项地方税费 + 6 项社保费
2. **多维度风险指标模型**：量化风险评分，识别虚开、阴阳合同、私户收款等高风险点
3. **合规应对指引**：正负面清单、七流一致整改、合规报告一键生成

## 常见问题

**Q：这个专家团适合谁？**
A：财税中介机构、税务师事务所、企业法务/财务人员。

**Q：如何处理复杂跨域诉求？**
A：主理人会识别所属领域，派单给对口专家，汇总后一体化交付。

**Q：如何补充业务细节？**
A：在对话中直接说明主体、金额、期间、交易结构等关键信息。

**Q：专家结论是否有政策依据？**
A：是的，所有结论均引用政策文号与条款出处，可溯源。
