# 银发旅游与无障碍服务团（Senior & Accessible Travel Team）

面向银发客群与行动不便人群，设计适老化行程、无障碍通行环境、随队医疗与安全保障方案。

## 类型

Team 型（多角色协作专家团），含主理人 1 名 + 团员 3 名。

## 团队成员

| 成员 ID | 名字 | 职业 |
|---------|------|------|
| senior-accessible-travel-team-lead | 乐龄行 | 银发旅游产品总监 |
| senior-itinerary-designer | 缓步游 | 适老化行程设计师 |
| accessibility-designer | 无碍行 | 无障碍服务设计师 |
| senior-safety-advisor | 康随行 | 银发安全顾问 |

## 使用示例

- 设计一条适合老年人的慢节奏旅游线路
- 景区无障碍环境改造应从哪些环节入手？
- 银发团的随队医疗与安全保障怎么安排？
